# E-Commerce Cross-Selling & Product Bundling Intelligence

**Project 02 — Intelligent Recommender Systems Research Lab**

Research-grade association-rule mining of real Olist Brazilian e-commerce orders (2016–2018). This repository is being built as a reproducible Apriori investigation, with strict chronological validation and held-out testing.

Dataset: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

**Status:** code under development; no empirical performance results are claimed until the original data have been acquired and experiments executed.
